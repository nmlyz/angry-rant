angry-rant is a tiny program that writes one short, funny rant about an everyday annoyance to a file. The rant is about a car that refuses to stop dinging because the bag of groceries in the passenger seat isn't wearing a seatbelt — so the oranges get buckled in, the car is satisfied, and the driver is not. The text is 200 characters long, well under the 400-character cap.

## Run it

```sh
python3 main.py
```

It writes the rant to `/output/entry.txt`. No network access needed; the same text, byte for byte, on every run.
